# 3. Intent Detection

## Responsibility

Convert natural language into a structured intent object.

## Input

- Current User Query
- Conversation History
- User Role
- User Context
- Current Session

## Output

```text
Intent
├── Intent Type
├── Entities
├── Confidence
└── Metadata
```

## Internal Components

```text
Intent Detection
├── Preprocessor
├── Intent Classifier
│   ├── Confidence Scorer
│   └── Intent Validator
└── Entity Extractor
```

## Possible Implementations

- Rule-based
- LLM Classification
- Hybrid

## Notes

- Multiple intents may exist in one request.

# 4. Planner

## Responsibility

Generate an execution plan for the user request.

Instead of directly calling tools, the planner decides:

- What steps are required
- Which tools should be used
- Whether there are dependencies among tools

## Input

- User Query
- User Context
- Intent
- Conversation Context
- Available Tools

## Output

```text
Execution Plan
```

## Internal Components

```text
Planner
├── Task Analyzer
├── Tool Selector
├── Dependency Analyzer
├── Plan Generator
└── Plan Validator
```

### Plan Validator Responsibilities

- Validate workflow correctness
- Check tool availability
- Determine whether user approval is required

---

# 5. Workflow Engine

## Responsibility

Execute the execution plan generated by the Planner.

## Input

- Execution Plan

## Output

- Execution Result

## Internal Components

```text
Workflow Engine
├── Workflow Executor
│   └── Retry Manager
├── State Manager
│   └── Error Handler
└── Tool Dispatcher
    └── Approval Manager
```

## Supported Features

- Sequential Execution
- Conditional Execution
- Parallel Execution
- Retry
- Timeout
- Compensation

# 6. Context Manager

## Responsibility

Build the prompt context for the current LLM invocation.

> **Memory Manager stores memory. Context Manager decides which information should be included in the current prompt.**

## Internal Components

```text
Context Manager
├── Conversation Manager
│   └── Knowledge Loader
├── Memory Loader
│   ├── Tool Context
│   └── Prompt Builder
└── Context Builder
    └── Token Budget Manager
```

---

# 7. Memory Manager

## Responsibility

Store, retrieve, and manage long-term memory across conversations.

The Memory Manager provides relevant memories to the Context Manager when needed.

## Internal Components

```text
Memory Manager
├── Memory Writer
│   └── Memory Store
├── Memory Retriever
│   └── Memory Ranker
└── Memory Indexer
    └── Memory Cleaner
```

# 8. Knowledge Retrieval (as Service)

In this architecture, Knowledge Retrieval is implemented as an independent service.

## High-Level Flow

```text
Agent
└── Planner
    └── Context Manager
        └── Knowledge Service
            ├── Retriever
            │   └── Vector Database
            ├── Re-ranker
            └── Query Rewriter
```

## Knowledge Service Pipeline

```text
Knowledge Service
├── Indexer
│   ├── Chunking
│   ├── Embedding
│   ├── Metadata
│   └── Vector Store
└── Retriever
    ├── Hybrid Search
    ├── Re-ranker
    └── ACL Filter
```

# 13. Latency Optimization

## Goal

Reduce end-to-end latency from user request to final response.

## Optimization Strategies

- Model Routing
- Prompt Compression
- Reduce LLM Calls
- Cache
- Parallel Execution
- Streaming Response
- Knowledge Cache
- Workflow Optimization
